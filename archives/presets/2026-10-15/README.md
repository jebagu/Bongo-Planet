# Bongo Planet preset archive

Original preset and portable composition JSONs saved before reducing the web app to Favorites on 15 October 2026. Every original byte was copied and SHA-256 verified; `manifest.json` records the source paths and hashes. Scene JSONs and complete music-and-look files remain importable.

The web app keeps Pachelbel’s Canon, Toy Ensemble, Airy Loops, Final Fantasy — Prelude · Reworked, North Pole Loop, and Tetris — Type A (Korobeiniki). This archive is outside the published application. The source fixtures remain available locally for engine regression checks and regeneration.

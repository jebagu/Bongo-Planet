# Thread the Needle

Three tiny G-pentatonic landmarks: kalimba, guitar and glass. Two out-of-phase sources keep trading the same sparse notes.

Two opposing entry points feed one 92-junction ring with two shortcut needles. Each source travels 64 hops; phase and path length produce the changing answers.

40 BPM; 16 beats / 24 seconds per loop. 2 finite generator(s), 3 sounding piece(s), 92 active routed junctions, 94 directed gates.

Choose **Load preset → Minimal Routing → Thread the Needle**, then **Play**. Preset loading starts paused and keeps the current look. To bring in its coordinated Moon chalk appearance too, import `Bongo-Planet.json` in the Composition section.

`preview.wav` is a 48 kHz stereo loop from Bongo Planet’s actual engine and current instrument recordings, with settled natural tails. `validation.json` records eight-cycle event and route stability, all reached instruments, bounded work and repeat-matched PCM. Offline validation does not claim physical listening or venue spatial-audio qualification.

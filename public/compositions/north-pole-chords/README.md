# North Pole Loop — chord arrangement

Four descending choirs of instruments, then a quiet return to the pole.

Sixteen three-note stacks voice Cmaj9 → Am9 → Fmaj9 → G9 across four registers and timbres. Empty breaths separate the changes; the original 24-hop meridians and silent returns remain.

Choose **Load preset → Chord Favorites → North Pole Loop**, then **Play**. Loading a preset starts paused and keeps your current look. Import `Bongo-Planet.json` to load the complete music and its coordinated look.

This is an instrumental loop arrangement: 6 master-grid beats at 40 BPM (9 seconds), with 16 chord stacks and 1 finite spark source. Each adjacent hop is one sixteenth note; simultaneous stack layers have independent voices without spawning more sparks.

# Blue Greenhouse

C-major-seven, F-major-nine and A-minor colors overlap like small sunlit rooms. Piano and guitar carry the low harmony; glass, kalimba and marimba answer above.

Four globe-spanning lanes interlock eight- and 16-beat sources with different phase offsets. Slow simultaneous layers and empty junctions give the harmony space.

40 BPM; 16 beats / 24 seconds per loop. 4 finite generator(s), 50 sounding piece(s), 92 active routed junctions, 88 directed gates.

Choose **Load preset → Airy & Ambient → Blue Greenhouse**, then **Play**. Preset loading starts paused and keeps the current look. To bring in its coordinated Lilac dusk appearance too, import `Bongo-Planet.json` in the Composition section.

`preview.wav` is a 48 kHz stereo loop from Bongo Planet’s actual engine and current instrument recordings, with settled natural tails. `validation.json` records eight-cycle event and route stability, all reached instruments, bounded work and repeat-matched PCM. Offline validation does not claim physical listening or venue spatial-audio qualification.

Recreate this collection with `npm run songs:ambient`.

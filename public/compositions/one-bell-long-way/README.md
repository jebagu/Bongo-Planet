# One Bell, Long Way

One D glass bell. The same note returns in small unequal clusters, with long stretches of silent spark travel.

A closed 92-junction circuit with two forward bypasses and a 104-hop budget. Copies return by different routes, revisit the single bell, then expire before the next launch.

40 BPM; 32 beats / 48 seconds per loop. 1 finite generator(s), 1 sounding piece(s), 92 active routed junctions, 94 directed gates.

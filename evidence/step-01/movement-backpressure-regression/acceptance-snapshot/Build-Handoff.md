## Launch and verify

From the project directory:

```sh
npm ci
npm run dev
```

In a second terminal:

```sh
npm run bridge
```

With the dev server and bridge running:

```sh
npm run verify
```

`verify` performs type/build, unit and installed-Chrome browser checks. The browser harness tests require the source dev server. For the production candidate, stop the dev server and run `npm run build` then `npm run preview`. Both use strict port 5417 and `/BongoPlanet/`; resolve an occupied port rather than changing the permanent URL. Chrome and video-tool requirements are in [README](../README.md).

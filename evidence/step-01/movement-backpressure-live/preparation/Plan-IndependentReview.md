# Bongo Planet — independent movement-backpressure feasibility review

**GO for bounded source preparation, with the corrections and prerequisites below. No actual invocation is approved by this note, and S01-A43 remains open.** This is a review of the proposed experiment and unchanged adapter/receiver contracts. No proxy, socket, browser, test, audio or helper was executed.

A raw TCP proxy can apply a real transport impairment without replacing WebSocket bufferedAmount or production movement policy. The plan correctly treats a small requested/effective receive buffer as an experimental setting, not proof that Chromium's exposed backlog will cross 65,536 bytes promptly. Two fresh, finite arms, legal public edits, unchanged production modules, explicit incomplete outcomes and no parameter-tuning retries make a useful bounded feasibility experiment possible. Success is not promised.

## Two plan corrections before source freeze

1. **Use the already reviewed combined build-identification chain.** Requiring another original loaded-worklet body would repeat a known acquisition requirement beyond this movement atom. Bind the actual original main response, its literal processor URL/addModule path, and explicitly separate served-processor hashes before/after with frozen sources. Do not label served bytes as an observed loaded worklet body. The two earlier UI witness failures remain failed; this plan does not revise them.

2. **Do not start the 500 ms proof at the first post-send high observation.** OutputAdapter captures `t` at entry to tick and can set `congested=t` later, after a position send crosses the threshold. Therefore a correct timeout can occur less than 500 ms after the later observer timestamp. If that crossing was the last position, initialization may instead occur on a following tick. A read-only sampler adds further phase/gap uncertainty. Preserve before/after send and bufferedAmount-read brackets, the original position `sent` value and selected fixed offset, all low/high observations and the close-call bracket. The original packet time minus the fixed offset gives a source-supported cached-t reference in the same browser domain, with the declared timestamp precision allowance. Use a conservative origin interval; do not subtract unaligned proxy/Node clocks or derive the origin by fitting the observed close. If an independent upper bound on actual detection is unavailable, report consistency/incompleteness rather than exact timer latency or a false early-close failure. Product thresholds remain unchanged.

## Required properties of the prepared implementation

**Transparent pause and bounded control.** Keep control/ACK traffic on a separate owned bounded channel, never the congested producer stream. A pause command is not a pause observation. ACK the actual change in read admission in the proxy's monotonic domain and retain any already-read or partly-written bytes that can still reach the receiver. Preserve each direction's FIFO and partial-write offsets. Limit each read to available queue capacity; a large read must not overshoot the 64 KiB queue and silently discard bytes. Handle zero progress, EOF, half-close, errors and invalid control messages explicitly. The proxy must never change WebSocket bytes, select musical frames or inject heartbeats. A backend error/close observed during impairment is a separately retained outcome; withholding ordinary reads does not make every possible TCP closure invisible or harmless.

**Short-arm feasibility.** Source must make the 250/350 ms decisions using actual pause/resume acknowledgements and conservative same-domain deadlines. Observe the native heartbeat associated with the active epoch, not merely a browser heartbeat send. A retained native row's observation time and lastHeartbeatHrNs establish its age in that domain; delivery delay makes stale state an insufficient resume certificate. Keep the original lease bound and reject an expired/wrong epoch. SO_RCVBUF readback, proxy queue occupancy, emitted movement volume or a requested pause cannot substitute for original socket bufferedAmount crossing. If the browser absorbs the allowed movement without crossing, the bounded result is threshold-not-reached.

**Latest-snapshot evidence.** Freeze the legal scene and permutations before the run. One disabled generator plus 91 sound nodes fits the 92-piece schema; two fixed sentinels plus 89 permuted nodes gives the intended contrast. Retain every public edit's actual timing and exact final scene. Stop edits at the predetermined state, allow the declared 120 ms motion to settle, and require fresh post-recovery records for both unchanged sentinels as well as all changed objects. Match original position sequences/session/object bindings and retain old queued records in their actual order. A later ordinary dirty update or final receiver state alone is not evidence of a full recovery snapshot. A successful drain without a real preceding high-buffer pause also cannot satisfy this conjunct.

**Sustained sender versus receiver events.** Both-direction pause is a useful way to separate the producer's own `close(1000, 'control backpressure')`/visible status from receipt of a server close frame. Still retain each observable actor and reason: the parent bridge's heartbeat watchdog and the native worker's own watchdog race. A native release caused by a forwarded parent stop is valid evidence of that route, not proof that native self-watchdog fired first. Natural voice expiry, clock invalidation, unexpected controls or receiver-close-first are distinct outcomes. Avoid causal phrasing that the sender close triggered a release if the watchdog had already released the receiver before the held close handshake.

**Positive release state.** An admitted eight-second note is schema-legal and improves on unchanged F05's .6-second note for this purpose. The optional prelude must retain actual local/receiver admission, positive native active state, the same epoch, no pending trigger and the remaining admitted lifetime at impairment. A 20-second startup allowance by itself does not ensure an eight-second voice is still alive. Require release before natural expiry in native hrtime with retained mutation brackets/reason and zero native pending/voices/objects afterward. Later buffered heartbeats must not revive the retired epoch. This proves numerical companion release only, not audible release or PCM continuity.

**Retention at the actual rate.** At 89 changing objects and at most 50 edits/second, source checks must account for the highest allowed send count and serialized sizes, not a low average. The bridge's 5,000-row rings and native diagnostics' 64-row tail require explicit overlap/gap checks or critical-phase retention; a final tail cannot stand for a complete high-rate stream. Retaining the native release while ingress is paused is plausible, but unavailable/overwritten rows must leave the release subset incomplete. Enforce the declared global 16 MiB trace, 8 MiB proxy bytes and per-direction queue bounds before retaining/writing; preserve the first exceeded bound and outstanding denominators. No source change to enlarge production rings or alter the lease is implied.

**Containment and cleanup.** Use exclusive fixed private ports with conflict failure, a separately scheduled controller watchdog, positively bound process identities/owned groups, bounded control messages and finite resource inventory. A same-process timer cannot contain a synchronous hang in that process. Reserve the full 20-second cleanup allowance within the proposed 100-second observed-controller budget and report host-scheduling limitations. Close proxy connections/listener, actual browser/context/AudioContext, private bridge/native worker/UDP and proxy process independently even if observation or evidence writing fails. Force or unknown closure must fail; control handles/pipes must be released separately from process-closure assertions. None of this authorizes stopping permanent services or unrelated processes.

## Acceptance boundary

An actual successful package could support S01-A43 only through its conjuncts: native bufferedAmount above 64 KiB suppresses movement sends; the same session drains and produces the newest full snapshot; a sustained real backlog causes the producer's visible congestion close under a conservatively supported timer interval; the real receiver releases through an identified watchdog route. One successful arm does not establish the other. Fixed-order/fresh-process arms demonstrate a bounded mechanism, not performance under arbitrary congestion or a unique explanation of earlier failures.

The proposed source can be prepared without replacing buffers, issuing private ticks, exceeding 50 Hz legal edits, flooding reliable controls, extending leases or changing tolerances. Its parser, partial-write, pause-ACK, deadline, ownership, cap and cleanup controls need independent source readback before root can consider a single actual. This note changes no production source, prior evidence or acceptance status.

# Bongo Planet movement-pressure successor — source preparation notes

This note describes the evolving successor only. Reviewed Plan02, the original helper and failed acquisition remain unchanged. No successor controls, compiler, browser, proxy, receiver or port probe have run since the root clock quiet window began. This is neither source GO nor an acquisition result.

The packet correspondence oracle preserves exact double XYZ equality between the producer position packet and receiver position record. Its separate OSC oracle uses the protocol's binary32 representation: each independently expected decoded coordinate is `Math.fround(wireCoordinate)`. Comparing raw OSC to the original double would reject healthy encoded coordinates; changing this representation check does not change the application's movement or timing thresholds. Controls include a topology-like coordinate that demonstrably has distinct double and float32 values, a changed double still within the same float32 bin, an incorrect float32 coordinate, reordered object IDs, and missing/extra receipts.

Public browser connection, context and page promises assign their fulfilled handles before a post-await stage check. If fulfillment occurs after acquisition abandonment, the handle is still assigned, its own close is attempted under a bounded two-second wait, and the attempt stays failed. Unsettled public acquisitions are explicitly rejected at cleanup disposition. Browser process ownership still derives solely from launchServer's child handle and the synchronous durable journal claim; no additional PID or process-group signal is introduced. Parent containment and successful exact closure remain external requirements.

The current native-state admission filter requires an observed worker state no older than 50ms at its Node reader upper endpoint. This is a stricter acquisition filter derived from two nominal25ms state intervals, not a promise that Node delivers state every25ms and not a new product gate. Missed or delayed states fail this experiment; they are not filled or assigned an invented uncertainty. The native heartbeat-to-reader150ms remaining lease check still has no implication for the unexposed parent heartbeat timestamp. Parent margin remains null/unknown and actual unchanged session/voice survival is required through complete drain.

An important unresolved feasibility limit is retained: every native position command produces an applied receipt, while production exposes only the most recent64 rows. A91-object drain flush can overwrite a previous retained row before the next requested20ms parent observation. The current helper follows the reviewed gap rule and fails rather than claiming complete worker history or increasing its ring. This can prevent acquisition qualification even when all wire/receiver/OSC packets and the final91-object snapshot are present. Any alternative treatment of noncritical applied-row loss versus release/cancel/clock-fault coverage requires a separately reviewed observation-scope decision before an actual run.

The draft keeps the fixed20ms legal edit chain, fresh two-second pressure windows, phase send ceilings summing to16,384, original150-edit ceiling, shared8MiB trace budgets, detected16MiB report budget and70s cumulative helper budget. Requested sampling intervals and in-process deadlines are cooperative observations; external root containment is required. No automatic retry or cap increase is implemented.

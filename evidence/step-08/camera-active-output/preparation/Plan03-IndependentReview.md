The proposed boundary is sound if the following implementation obligations hold:

- **Retention must not control checking.** Every original drain/poll must still execute the existing health, lifetime, clock, session, running/context, prefix-integrity and capacity checks. Event/wire/pointer ingestion must run even when local telemetry is an unchanged reread. Native original-row ingestion and the complete 64-row overlap algorithm must run even when the parent mirror is omitted. No sampling cadence or in-flight observation semantics should change.
- **Local equality must be exact for the retained semantic fields.** Compare the full status value plus adapter and context state, retaining every advancing `status.time` and every same-time semantic transition. Ignoring parent/browser receipt brackets and changing `audioNow` for equality is reasonable only because they are validated on every poll and the omitted values' declared summary is not promoted into a new processed status. Null status disappearance, backwards time and changed error/voice/sequence/pending/session state must still fail or be retained as specified.
- **Native mirror equality must cover the declared health projection.** Keep readiness, failure/evidence failure, uncertainty, incarnation, pair sequence, session/pending/voice/drop state and existing worker projection in the signature. Omitting a changed `clockPairAgeMs` or read bracket alone does not remove the independent clock pairs or authoritative original worker rows. It also does not establish a continuous diagnostic time series. A newly failing reading must be retained before its assertion when capacity permits, or leave an explicit failure if it cannot fit.
- **Required witnesses must remain actual fresh observations.** Before/during/after selection must use original retained local observation brackets and distinct advancing processed times, plus original timestamped native rows. An omitted-read count, latest omitted bracket, summary materialization time or repeated status cannot satisfy a fresh witness or replace a missing interval.
- **The budget must still cover every new retained value.** Fixed-size omission accumulators may keep only the declared bounded counters/bracket endpoints/extrema, with no uncharged list of omitted readings. Charge their materialized snapshot before appending it at existing checkpoint/finalization boundaries. Account for cumulative counters versus summary deltas explicitly so retained-plus-omitted denominators can be reconciled without double counting. If a summary/failure observation cannot fit, keep the budget poison and failed disposition; do not quietly omit it and claim a complete denominator.

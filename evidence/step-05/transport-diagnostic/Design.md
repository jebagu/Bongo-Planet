# Bongo Planet — retention transport comparison design

Source preparation only. Live capture remains held for root's quiet GO and independent review. Production, original captures, audio settings, default view and original F06 fixture are unchanged.

Two independently planned arms each request24 actual seconds after first logical emission plus matching-session running telemetry: the existing exposed-function combined retention path, then a dedicated localhost WebSocket path. Both use a fresh owned Chrome process/context/page, actual product destination plus the same silent dual-input observer, exact named SPAT virtual input/output,32×128 sample batches, full original event rows and independent128 pending caps. The original event handler runs exactly once. First logical epoch and arrival clocks remain separate; no endpoint is fitted to PCM or rebased after delayed activation.

The socket path sends little-endian native Float32 bytes without Array.from or PCM serialization through the browser automation protocol. A28-byte header binds magic/version/kind/sequence/JSON length and source/input sample counts; bounded JSON metadata precedes exact source then input bytes. Events travel as bounded JSON text, converted to the same canonical retained frame. Both transports compare original browser byte checksums against Node's reconstructed/received Float32 bytes; nonfinite original JSON trees are rejected before stringification. Negative-zero loss in the JSON baseline is an explicit failing corruption control rather than an accepted repair.

Both collectors append a four-byte frame-length prefix and the complete canonical frame to one container before acknowledging its stream, sequence and byte count. Synchronous writes may require multiple write calls; incomplete writes are retained with their actual partial byte counts. No filesystem transactional/fsync guarantee or cross-file atomicity is claimed. A first decoding, validation or append failure terminally poisons the collector, refusing all later stream writes/ACKs. After capture closes, derived raw Float32, ordered per-quantum metadata and full event rows are copied from complete validated container frames; any unparsed original tail is retained and explicitly failed.

Bounds:256KiB per frame,64MiB/4096 retained frames per arm,8MiB browser and Node ACK send buffers including the next actual wire payload,12,000 browser trace rows,4,096 Node callback rows,90-second soft and100-second hard total. The socket binds IPv4 loopback5424 and admits one connection with exact diagnostic origin and ephemeral capability. It changes no permanent project URL or product protocol.

Browser records original-handler, payload construction, synchronous dispatch/send, matching ACK settlement, heartbeat, frame gaps, long tasks, pending counters, first actual errors/overflows and censored unresolved requests. Node records entry, reconstruction/wire decode, frame decode, validation, complete write and ACK enqueue boundaries. Browser and Node clock origins are separate. Send-to-ACK distributions use settled observations only and explicitly retain censored denominators. Node ACK enqueue is distinct from browser receipt. No transit duration is inferred by subtracting unrelated clock origins.

The planned fresh socket arm may follow an exposed-arm incomplete acknowledgement drain only after complete page/context/AudioContext/track/browser-process/socket-server/container-descriptor closure, zero active Node callbacks and closed admission, valid full retained frames, and matching accepted dispatch denominators are positively confirmed. Any other actual error or unconfirmed cleanup stops remaining work. The original exposed failure stays failed; the overall experiment remains failed if any arm fails. This is the second preplanned control, not a retry.

Fixed ordering, fresh short exposures, new checksums/framing/ACK validation, diagnostics, transport limits and synchronous container persistence are perturbations and confounds. Results can compare these measured pipelines, but cannot assign the old warm third-segment failure uniquely to IPC, disk, product event handling or deferred UI/render/GPU/GC. No onset, physical output, human listening or acceptance qualification follows.

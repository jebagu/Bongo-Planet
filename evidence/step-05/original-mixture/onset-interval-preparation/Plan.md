# Bongo Planet — interval primitive preparation

Source only. This module will read no PCM, create no runner, enumerate no ownership branches, and make no timing or qualification decision. The frozen scalar oracle and all previous results remain unchanged.

The proposed API is a small binary64 interval type plus outward add/subtract/multiply/divide/intersection/hull, real sine/exp/tanh enclosures, scalar sine/kick voice ranges and a fixed-active-ownership mixture range (maximum64 voices). Inputs are exact represented binary64 parameters; the supplied time/origin range and active membership must already belong to one proven ownership branch. The module does not certify frequencies produced by an external Math.pow, unknown production clock history, admission/steal ordering, joint aliases, or Float32 recording compatibility.

Each primitive basic arithmetic endpoint expands by one representable number using integer IEEE754 bit stepping. Nonfinite/undefined operations use an honest unbounded fallback or reject an invalid domain. Transcendentals use interval Taylor sums and explicit factorial/Lagrange remainder bounds, not sampled grids or an unexplained epsilon. Sine reduces by an integer multiple of a documented enclosing interval for real pi; that integer choice is only a heuristic and does not affect validity because the reduced interval is checked. Unsupported large/reduction domains return [-1,1]. Exp scales to absolute argument≤1/8, uses a Taylor remainder bounded by the geometric-series inequality exp(1/8)≤8/7, then repeatedly squares; unsupported arguments return a conservative positive range. Tanh uses monotonic endpoint evaluation and bounded exp; large arguments use proved saturation bounds.

These are enclosures of the declared **real analytic functions**. JavaScript Math.sin/exp/tanh implementation accuracy is not assumed or certified. In particular, agreement of later production PCM with these bounds needs a separately justified implementation/rounding error model. The module will expose that distinction explicitly and never call such a comparison certified from this preparation alone.

Voice envelope min branches and the onset/end zero branches will be enclosed, including a zero alternative when origin intervals cross them. Supplied membership remains fixed: this does not prove membership stays fixed across an origin/admission cell. Saturation is applied after the ordered real mixture enclosure. No ordinary missing/duplicate or acoustic identity conclusion follows.

Controls will use rational special cases and independently tabulated high-precision vector enclosures, including off-grid/tiny intervals, turning points, wide fallbacks, IEEE boundaries, onset/duration edges and capacity rejection. They will not use the frozen scalar implementation as the expected oracle. A small rational Taylor calculation may independently verify chosen vector bounds; fine-grid sample agreement is supplementary only.

Resource bounds: no frontier/search or sample allocation;≤64 voices, fixed Taylor degree and bounded reduction/scaling iterations per evaluation. Constant-size interval objects only. Source controls and typecheck are allowed; no actual PCM algorithm/capture/service/browser execution is authorized.

The delivered waveform API also accepts triangle/hat/snare only as explicit broad amplitude alternatives. Noise seed/sample-index transitions, triangle asin branches and external cancellation fades are not split or certified. Scalar coefficients/frequencies are exact supplied binary64 values. No Float32 conversion or production JS Math error bound is provided. Structural work is constant per call: at most64 supplied voices,15 sine recurrence steps plus33 remainder steps,18 exp steps plus19 remainder steps and at most10 squarings; no PCM or frontier allocation. This is not a measured resource certificate for a future search.

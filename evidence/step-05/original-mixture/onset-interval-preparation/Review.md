# Bongo Planet — interval preparation scope

The small pure module supplies outward IEEE754 binary64 interval arithmetic and enclosures for real sine, exponential, tanh, sine/kick envelopes and an ordered mixture of at most 64 supplied active voices. It reads no recordings and contains no search, epoch alignment, admission/steal assignment, acoustic identity decision or qualification runner. Frozen oracle, production sources, recordings and existing decisions are unchanged.

Basic operations assume standard binary64 round-to-nearest arithmetic; each endpoint is expanded by a representable step. Sine uses a checked integer reduction by the real-pi bracket and a degree 32 Taylor polynomial whose coefficient 32 is zero, with derivative 33 remainder≤|x|^33/33!. Exp scales to |x|≤1/8, uses degree 18 plus exp(1/8)≤8/7 remainder and bounded repeated squaring. Tanh is monotone and uses endpoint evaluation; its large-argument bound follows e>2 and 2/(e^64+1)<2^-63<2^-53. Unsupported transcendental domains retain explicit conservative ranges rather than a sampled-grid certification.

The independent controls derive real-pi bounds via rational Machin/arctan alternating remainders and an exact tangent identity. Reference sine/exp vectors use direct degree 162 sine (zero coefficient162, highest nonzero degree161, remainder163) and degree120 exp rational series with independently justified remainders, rather than the module's reduction/scaling algorithm. Voice vectors compose those exact rational enclosures. All endpoint conversions are checked against their rational bounds. Fourteen reference vectors plus IEEE/domain, continuous/turning-point and voice/mixture boundary tests give 23 passing tests; no production scalar implementation or PCM is used as their expected values.

The first independent reference generation completed exit0 but exceeded its initial 10-second yield and subsequent 5-second wait. A requested SIGTERM found the owned PID already absent: it did not kill a live generator. The exact elapsed runtime was not retained and is not invented. Its source/vectors and truthful terminal record are preserved; an outward rational-lattice compression variant is source-only/unrun. The ordinary module test run completed in 123ms. An evidence snapshot path-expression mistake was corrected after its metadata write and retained separately; it was not a failed mathematical control.

Every returned enclosure labels the real-analytic model and explicitly sets JavaScript Math accuracy certification false. Real pi/supplied binary64 coefficients are not a proof of production Math.PI/expression rounding, including the production kick's 105×.022 coefficient evaluation. Frequencies are supplied values, not certified external Math.pow results. No Float32 output-conversion allowance or production transcendental implementation error model is supplied. Recorded-PCM compatibility therefore cannot be certified by this module alone.

The active ownership list must already belong to a proved branch. Origin intervals are enclosed through attack/end branches, but active membership changes, admissions, voice stealing, external cancellation fades and joint/whole-period aliases remain unimplemented. Triangle asin and hat/snare seed/sample-index transitions retain broad explicit alternatives; noise branch splitting is not implemented. Saturation is enclosed only for the supplied mixture. There is no claim that a future complete acoustic search will fit 120 seconds/256MiB or identify 120 groups.

Useful feasibility: this provides real-function exclusion ingredients for small, already-established sine/kick ownership cells. Broad dependency bounds and unsupported alternatives can leave a cell unresolved. Remaining production error models, branch certification, attack discrimination, ownership/admission alternatives, joint aliases and actual recording analysis must be independently completed before any onset qualification. `qualificationPassed` remains false.

# Bongo Planet — numerical discrepancy diagnostic plan

Source preparation only; no new recording or production change. The original fixed-fidelity result and its strict F06/F08 maximum-error failures remain immutable. A source-reviewed, separately authorized invocation would create only `numerical-discrepancy.json` and refuse to overwrite an existing result:

```sh
npx tsx scripts/mixture-numerical-discrepancy.ts evidence/step-05/original-mixture/binary-capture-01
```

The helper binds the successful independent audit, existing fixed-fidelity result, full untouched metadata/event/raw hashes, unchanged oracle and captured processor/synth source. It does not repeat container or native-click auditing. It retains the fixed original group/window denominator and reports diagnostic completion separately from acceptance, which remains false.

First it compares every declared positive-fixture logical trigger against the retained actual trigger/onset records by session, sequence, generator and node. Analytic onset is the unchanged oracle's original first-emission epoch plus period/travel calculation. It reports emission/onset deltas, scalar sound-parameter disagreement, missing/extra/duplicate ledger rows and the complete matched count. These are retained logical records, not independently detected PCM onsets. It does not fit an origin or silently require event and model agreement.

For F06/F08 it reproduces the unchanged full fixed-window oracle once, retaining the same first/last original indices, and ranks the sixteen largest absolute discrepancies. At these predeclared samples it retains the raw sample, nominal oracle sample, exact ordinal/frame/block metadata, active analytic ownership identities and admission/removal boundaries. Per-voice age and scalar contribution permit source inspection; scalar reconstruction must reproduce the original oracle sample. This is analytic ownership, not a directly observed product active-voice snapshot.

The first stage does **not** evaluate alternate arithmetic expressions, accumulation orders or simulated production cursors. Root's possible cumulative cursor/emission rounding mechanism remains a hypothesis. A later separately reviewed diagnostic could contrast those declared calculations and conservative derivative bounds if the retained timestamp and top-sample observations justify it; nothing is fitted or substituted for the fixed epoch here.

The helper uses cooperative120s/RSS256MiB guards. Synchronous oracle rendering is checked before/after and cannot be interrupted by the helper; resource bounds are detected limits rather than a preemptive watchdog. Full hashes are streamed; dense windows are processed sequentially. All raw files and original reports/manifests remain unchanged. No threshold relaxation, PCM repair, rerun of the original fidelity criterion, global timing uniqueness, acoustic missing/duplicate exclusion, or acceptance update is performed.
